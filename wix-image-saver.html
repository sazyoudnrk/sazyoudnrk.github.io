Wix画像まとめ保存

元のWixサイトの画像を、新サイトで使う名前に付け替えてzipで保存します。

使い方
1. このファイルをGitHub Pagesに上げて、そのURLをSafariで開く（ファイルを直接開くと動かないことがあります）
2. 下のボタンでzipを保存 → ファイルアプリで解凍
3. 解凍してできた images フォルダの中身を、GitHubの Add file → Upload files で上げる
保存できなかったときは、下の一覧の画像をタップして開き、長押しで保存してください。名前は画像の下に出ている通りに付けます。

枚数が多くてメモリが足りないときは、各見出しの横のボタンで分けて保存してください。
