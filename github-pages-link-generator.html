GitHub Pages 公開リンク作成ツール

GitHubのユーザー名・リポジトリ名・HTMLファイル名を入力すると、 リポジトリ作成用URLと、HTMLファイル作成用URLを自動生成します。

スマホだけでGitHub Pagesに公開する手順

  1. GitHubで新しいリポジトリを作成します。
    リポジトリ作成ページを開く
    Repository nameを入力し、Publicと「Add a README file」を選んで作成します。
  2. リポジトリができたら、HTMLファイルを作成します。
    HTMLファイル作成画面を開く
    HTMLコードを入力し、Commit changesで保存します。
  3. リポジトリの Settings → Pages を開きます。
    GitHub Pages設定を開く
  4. Build and deployment の設定を次のようにします。
    • Source：Deploy from a branch
    • Branch：main
    • Folder：/ (root)
    Saveを押します。
  5. しばらく待つとサイトが公開されます。
    公開URLは https://ユーザー名.github.io/リポジトリ名/ です。
index.htmlについて
ファイル名を index.html にすると、 公開URLの末尾にファイル名を付けずにアクセスできます。 例：https://ユーザー名.github.io/リポジトリ名/

注意

  • GitHub Pagesで公開するファイルは基本的に誰でも閲覧できます。
  • HTMLやJavaScriptにAPIキー、パスワード、アクセストークンなどの秘密情報を入れないでください。
  • 独自ドメインを使わない場合、GitHub Pagesの「Custom domain」は設定不要です。
