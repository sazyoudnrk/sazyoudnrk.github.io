PP1 パンチ

画像 → 刺しゅうステッチ

塗り画像だけでも動く。その場合は減色後のパレットから線の色を指定する。

画像を選んで「減色」
パレット

タップで「線」に切り替え。線に指定した色は塗らずに、中心線をたどってサテン／ランニングで縫う。

使い方

1. 画像を用意する

最大3枚。塗り画像だけでも動きます。

  • 塗り画像 — 完成イラスト。これが色の元になる
  • 線画 — 線だけのレイヤー。中心線をたどってサテンかランニングで縫う
  • 枠線 — 外枠。他が全部終わったあと、いちばん最後に縫う

3枚は同じサイズ・同じ位置で書き出してください。透明部分は「外側なら縫わない／内側なら背景色で埋める」と判定します。

2. 減色 → ステッチ生成

「減色」でパレットを作り、必要なら色をタップして 塗り／線／縫わない を切り替え。布と同じ色は「縫わない」に。そのあと「ステッチ生成」。

設定を変えたら「ステッチ生成」だけ押せば反映されます。色数や解像度を変えたときだけ「減色」からやり直してください。

3. プリセット

繊細な線は細いペン画や小さい顔向け。太い線は太い主線やベタが多い絵向け。塗りだけは線を縫きません。迷ったら標準から。

4. 縫う順パネル

  • 行をタップ → その色だけプレビューで濃く表示
  • ↑↓ → 縫う順を入れ替え（糸切りの判定もやり直す）
  • 毎回／長い時／切らない → その色の糸切りの方針
  • チェック2つ以上 →「選んだ色を1色にする」。塗り・線・枠線をまたいでまとめられます

5. 書き出し

「PESで書き出す」で .pes を保存 → Artspiraのインポートから読み込み → PP1へ転送。糸色はブラザーの64色に丸められ、書き出し後に対応表が出ます。

文字を入れる

「文字」パネルにテキストを入れると、書体の輪郭をそのまま刺しゅうにします。画像なしで文字だけでも作れます（文字を入れて「減色」→「ステッチ生成」）。

  • 縫い方 — 〈自動〉は細い所をサテン、太い所を塗りにします。10mm以下の小さい文字は〈サテン〉、大きい文字や極太は〈塗り〉が安定します
  • 書体 — ゴシック系がいちばん綺麗に出ます。明朝はハネや払いが細く、5mm以下だと潰れます
  • 絵は今まで通り最後まで縫って、その上に文字を重ねます。土台があるぶん文字が沈まず綺麗に出ます
  • 二重に縫うのを避けたい場合は「文字の下の塗りを抜く」をオンに
  • 縫う順は 塗り → 線 → 文字 → 枠線 です

市販の刺しゅうソフトは書体ごとに手作業でサテンの振り方を作り込んでいます。このアプリは輪郭から中心線を割り出す方式なので、交差や serif の付け根では市販品ほどの精度は出ません。ゴシック体で8mm以上あればまず問題なく縫えます。

プレビューの見方

「渡りと糸切り」をオンにすると、針の動きが3種類で表示されます。

  • 糸色の実線 — 実際に縫われるステッチ
  • オレンジの点線 — 糸を切らずに移動する。この糸は布の上に残ります
  • 赤い丸 → 赤い点 — 丸の位置で糸を切り、点の位置から縫い直す。間の点線は針の移動で、糸は残りません

下打ちは薄く描かれます。細い薄線が輪郭のなぞり、粗い斜めの網が土台のフィルです。

統計の「切らない渡り」が、実際に布の上に残る糸の本数と最長距離です。ここが0なら露出する糸はありません。

糸切りの回数を減らすには

糸切りが増えると刺しゅうの失敗率が上がります。ただし減らしすぎると糸が布の上に残ります。以下の順で試してください。

  • 「切らずに済ませる渡り」を上げる（既定1.5mm）。この長さ以下の移動は切りません。2〜3mmまでなら残る糸は短く、次の縫いで押さえられることが多い
  • 「最小領域」を上げる。統計の「領域」が糸切り回数の下限です。細かい島が多いほど切る回数が増えるので、吸収させると減ります
  • 縫い角度を変える。丸い形や穴のある形は0°か90°にすると激減します。斜めに走査すると穴の接線で細かく分断されるためです
  • 色をまとめる。縫う順パネルで似た色を1色にすると、糸替えの回数ごと減ります
  • 色ごとに指定する。⚙ボタンで色ごとに角度・行間・下打ちを変えられます。「毎回／長い時／切らない」も色単位です

つまずいたら

  • 細い線が消える — 線パネルの「細すぎる線」を〈太らせて必ず縫う〉に、「最小の線長」を下げる
  • 余計な線が出る — 「最小の線幅」を上げる。枠線は〈塗り〉で縫うと確実
  • 糸切りが多すぎる — 基本パネルの「糸切りの方針」を〈色を変えるときだけ〉に
  • 枠の下から色がはみ出す — 枠線パネルの「枠線の外は縫わない」をオン
  • 絵にない細い帯が出る — 画像の端にできる半透明のフチが領域として拾われています。塗りパネルの「最小の塗り幅」を上げてください
  • 縁がガタつく — 塗りパネルの「下打ちに輪郭を入れる」をオン。縁を先に走り縫いでなぞって形を固定します
  • 生成が重い — 解像度を8px/mmに下げる。行間はそのままでよい
  • ステッチが多すぎる — 行間を0.25mm前後に、下打ちをオフ

覚えておくこと

枠は10×10cmまで。糸は0.4mm前後の太さがあるので、1mm以下の描き込みは原理的に潰れます。顔が小さい絵は、顔だけ線を太くした線画を別に用意すると効きます。

刺しゅうデータの書き出し

ステッチを生成してから押すと .pes を保存します。糸色はブラザーの64色パレットに丸めます。

iPhoneでは共有シートが開くので「ファイルに保存」を選び、Artspiraの「インポート」から読み込んでください。

設定の保存

パラメータ・プリセット・色ごとの糸切り指定を1つのJSONにまとめます。画像は含みません。同じ絵柄シリーズを同じ設定で作るときに。

縫う順

行をタップするとプレビューでその色だけが濃く出る。「切る／切らない」は色ごとに指定できる。矢印で縫う順を入れ替えると、糸切りの判定もやり直す。
